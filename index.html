Quick Reference

Unified Command Syntax

Identical syntax works across both Telegram and Email channels.

Command Arguments Channels Description
/sub <type> <arg> Type: gateway | rss
Arg: API token or Feed URL		 Telegram + Email Creates a new notification subscription.
/unsub <type> <arg> Type: gateway | rss
Arg: UUID, Token, or Feed URL		 Telegram + Email Removes the subscription and terminates webhooks.
/subscriptions (None) Telegram + Email Lists active subscriptions with status and delete controls.
/help (None) Telegram + Email Displays syntax help, supported types, and examples.
/cancel (None) Telegram only Aborts an active step-by-step interactive prompt.
